# Data Toolkit Showcase — scheduling

Workspace for the showcase-week live-demo block.

- `live_demo_poll.json` — availability census from the scheduling poll. Each
  period lists its 30-minute slots; every slot carries the presenter IDs that
  are available for that slot. `required_presenters` is the full roster and
  `block_minutes` is the length of the single block we need to book.
